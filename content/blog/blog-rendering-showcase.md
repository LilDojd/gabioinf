## Rust highlighting

The Rust grammar runs during the build. The browser receives only HTML and CSS.

```rust title="sequence.rs" {9-14}
#[derive(Debug, Clone, PartialEq)]
struct Sequence<'a> {
    id: &'a str,
    bases: &'a [u8],
}

impl Sequence<'_> {
    fn gc_fraction(&self) -> f64 {
        let gc = self
            .bases
            .iter()
            .filter(|base| matches!(base, b'G' | b'C'))
            .count();

        gc as f64 / self.bases.len() as f64
    }
}
```
